# fr24-tracker
## 基本功能
程式利用呼叫**flightradar api** 擷取特定航班資料，並以**discord**通知使用者\
程式會定期定時調閱api資料庫，提供四大功能資料：\
\
**追蹤特定飛機/航司不特定飛機是否前往TPE**，例如*JA787A*或*ANA*\
**追蹤特定飛機是否在TPE地面**，例如*JA787A*\
**追蹤特定航線有無飛機飛行**，例如*LHR-TPE*航線\
**追蹤特定航班號有無飛機飛行**，例如*ANA9415*號航班
## 環境設定
Name：`FR24_API_TOKEN` ／ Secret：貼上你的 Flightradar24 API Token（測試階段可先放免費的 Sandbox Token）。\
Name：`NOTIFY_WEBHOOK_URL` ／ Secret：貼上你的 Discord Webhook 網址（若暫時不設定，程式只會在執行紀錄中印出文字，不會報錯）。
## 追蹤特定飛機/航司
### 模組名稱
`track_fleet_tpe.py` 與`track_fleet_tpe.yml`
### 飛機與航司設置
於`track_fleet_tpe.py`內
```
# 1. 設定要追蹤的目標飛機註冊編號
TARGET_REGISTRATIONS = [ #加入想追蹤的飛機註冊號]

# 2. 設定要追蹤的目標航空公司 3 碼 ICAO 代碼（可逗號擴充多間）
TARGET_AIRLINES_ICAO = [ #加入想追蹤的航空公司 3 碼 ICAO 代碼]
```
例如
```
# 1. 設定要追蹤的目標飛機註冊編號
TARGET_REGISTRATIONS = ["JA787A", "B-18001","D-ABPB"]

# 2. 設定要追蹤的目標航空公司 3 碼 ICAO 代碼（可逗號擴充多間）
TARGET_AIRLINES_ICAO = [ "BAW", "ANA", "GTI"]
```
### 偵測時間設置
於`track_fleet_tpe.yml`內依需求修改，本案為周一至周五固定由05:00、06:00、07:00、16:00、17:00偵測；周六及周日於07:00至17:00每小時偵測，且當成功命中加入23.5小時冷卻機制
```
schedule:
    # 【平日週一至週五】台灣時間 05:00, 06:00, 07:00 -> 對應 UTC 週日至週四 21:00, 22:00, 23:00
    - cron: '0 21,22,23 * * 0-4'
    # 【平日週一至週五】台灣時間 16:00, 17:00 -> 對應 UTC 週一至週五 08:00, 09:00
    - cron: '0 8,9 * * 1-5'

    # 【週末週六與週日】台灣時間 07:00 -> 對應 UTC 週五與週六 23:00
    - cron: '0 23 * * 5,6'
    # 【週末週六與週日】台灣時間 08:00 至 17:00 每小時 -> 對應 UTC 週六與週日 00:00 至 09:00
    - cron: '0 0-9 * * 6,0'
```
若自訂義冷卻時數，則於`track_fleet_tpe.py`內依需求修改，本案為23.5小時
```
# 設為 23.5 小時，避免隔天同一小時因排程提前數秒觸發而誤判仍在冷卻期
COOLDOWN_HOURS = 23.5
```
## 追蹤特定飛機是否在TPE地面
### 模組名稱
`track_multi_24h.py` 與`track_multi_24h.yml` 與 `targets.json`
### 飛機設置
於`targets.json`內依需求修改
```
{
  "registrations": [ #輸入想要追蹤的飛機編號
    "OE-LPF",
    "PH-TFJ",
  ]
}
```
### 偵測時間設置
與前述相同，於`track_multi_24h.yml`內依需求修改
## 追蹤特定航線有無飛機飛行
### 模組名稱
`track_route.py` 與`track_route.yml`
### 飛機設置
於`track_route.py`內依需求修改，加入想要追蹤的航線，得設定排除條件
```
# ==============================================================================
# 【航線與排除規則設定區】— 修改此區塊可新增或刪除條件
# 說明：
#   1. "exclude_airlines"：填入 3 碼航空公司 ICAO 代碼
#      常見代碼：CAL=中華航空, EVA=長榮航空
#   2. "exclude_flights" ：填入特定排除的「航班號」或「呼號」（如 CI82, CAL82）
# ==============================================================================
ROUTE_CONFIG = {
範例於此
    "ANC-TPE": {
        "exclude_airlines": ["CAL", "EVA", "SJX"],
        "exclude_flights": ["5X500","UPS500"],
    },
在這邊新增航線、排除航司或航班號
}
```
